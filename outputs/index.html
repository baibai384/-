先学更换背景
最常问的问题

更换背景，需要换哪些文件？

主背景文件是 abj.png。资料明确标注：abj = 背景＋顶栏，顶栏通常已经贴在背景图上方。

必须替换 · 浅色模式底包 / skin / light / res / abj.png
有深色模式时也要替换底包 / skin / dark / res / abj.png
还要检查：如果 land 或 port 目录中还有同名 abj.png，它们通常控制横屏或竖屏，也要制作对应尺寸的版本。请在整个底包中搜索“abj”。
  1. 备份：复制原来的 abj.png。
  2. 当模板：导入 Procreate，保持画布宽高不变。
  3. 换图片：铺满新背景，保留顶栏所在区域。
  4. 原名导出：导出 PNG，仍命名为 abj.png。
  5. 覆盖测试：放回原目录，检查横竖屏与深浅模式。

按键辅助图

先对准 KEY 位置，再画贴图

把辅助图放在 Procreate 最底层并降低透明度。在新图层制作，导出前隐藏辅助图，不要把 KEY 编号和网格导入成品。

同一个 KEY 编号在不同布局里可能是不同功能，必须对着当前布局的辅助图使用。
完整制作顺序

一次只替换一类素材

  1. 打开底包：分享到解压专家，解压后找到 skin/light/res。
  2. 更换背景：替换 abj.png，深色模式中的同名文件也要处理。
  3. 更换按键：普通状态和按下状态成对替换，保持原尺寸和文件名。
  4. 更换前景：qj 是字母/数字文字，gnqj 是功能键前景，qja 是按下状态字母。
  5. 更换 Logo：检查 res/logo；苹果顶栏图标通常在里面的子文件夹。
  6. 更换动效：在 anim.ini 找到 PARTICLE_IMAGE，新手先只换同名 PNG。
  7. 更换声音：替换同格式 AIFF/OGG，并检查 default.css 的 PRESS_SOUND_PATH。
  8. 修改文字颜色：在 default.css 搜索 FONT_COLOR、HL_COLOR、NL_COLOR。
  9. 打包测试：压缩包根目录应直接看到 skin，不要多套一层文件夹。
故障排查

出错时先检查这些地方

无法导入

检查是否多套目录、扩展名是否正确、配置是否改坏。

图片不显示

检查文件名大小写、后缀、目录和配置引用。

图片错位

检查画布尺寸、横竖屏素材和人物是否超出画布。

没有声音

检查真实音频格式、文件名、声音路径和手机设置。

文字看不见

检查颜色格式、背景对比度和按下状态颜色。

动效不显示

检查 anim.ini、粒子 PNG、透明度和参数是否为 0。

不要直接删除不喜欢的素材：先备份，再在 default.css 和 anim.ini 中搜索文件名。仍被引用时，优先换成透明占位图或正确移除引用。
